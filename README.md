## 📋 Overview 📖
**Amazon Clone** is a fully responsive **e-commerce interface** built using **HTML, CSS, and JavaScript**.  

💡 It replicates:
- 🛒 Product listing layout  
- 🧭 Navigation structure  
- 📱 Responsive UI  

Designed purely for **learning and frontend practice**.

---

## ✨ Features 🌟

- 🏷️ Product cards (image, name, price)  
- 🛍️ Navigation bar for browsing  
- 📱 Fully responsive design  
- 🎯 Interactive buttons (Add to Cart)  
- ⚡ Lightweight and fast  

---

## ⚠️ Note 🚧

- ❌ No backend integration  
- ❌ No real database  
- ❌ No payment system  

👉 This is an **educational project only**.

---

## 🛠️ Tech Stack ⚙️

- 🧱 HTML  
- 🎨 CSS  
- ⚡ JavaScript  

---

## 🎯 Project Purpose 🎓

This project was built to:

- 🧠 Understand e-commerce UI structure  
- 🎨 Practice responsive frontend design  
- ⚡ Improve JavaScript interactivity  
- 🚀 Build real-world UI clones
